# usage
When you first download the program, or every time you re-download `quotes.txt`,
you will want to run ```python3 update_indices.py``` (or download `indices.idx` too).  
Generally, run with ```python3 get_quotes.py``` or put that in your `.bashrc` file.

## sources for quotes
Public-domain quotes largely sourced from Project Gutenberg (gutenberg.org)
